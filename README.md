## About

**NEXTHON Community** is the collaborative space for developers learning, experimenting with, and building projects using the NEXTHON programming language.

Whether you're a beginner writing your first program or an experienced developer creating something more advanced, you're welcome to contribute.

Our goal is to build a growing collection of NEXTHON examples, tutorials, challenges, and community projects.

## What can you contribute?

| Category | Description |
|---|---|
| Beginners | Simple programs for new NEXTHON developers |
| Examples | Useful `.ne` code examples |
| Tutorials | Step-by-step learning resources |
| Challenges | Programming exercises and solutions |
| Projects | Small applications and experiments |
| Documentation | Improvements to guides and explanations |

## Getting Started

### 1. Install NEXTHON

Get the language from the official repository:

[**NEXTHON – Main Repository**](https://github.com/Nexform-star/NEXTHON)

### 2. Install the VS Code Extension

[**NEXTHON Language – Visual Studio Marketplace**](https://marketplace.visualstudio.com/items?itemName=nexform.nexthon-language)

### 3. Write your first program

Create a file named `hello.ne`:

```ne
print("Hello, NEXTHON!")
print("Welcome to the community.")

var developer = "YourName"
print("Developer: " + developer)
```

Run it with the NEXTHON interpreter.

## Contributing

Contributions are welcome!

We use GitHub Issues and Pull Requests to organize and review community contributions.

**Our contribution workflow:**

1. Open an Issue describing your idea or proposed contribution.
2. Wait for maintainer feedback and approval.
3. Fork this repository and create a branch.
4. Add your contribution.
5. Open a Pull Request referencing the original Issue.
6. Wait for review.

All Pull Requests are reviewed before being merged into the `main` branch.

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting your work.

## Community Guidelines

- Be respectful and constructive.
- Keep examples readable and understandable.
- Submit working NEXTHON code whenever possible.
- Explain what your contribution adds.
- Follow the repository structure.
- Do not submit malicious or harmful programs.
