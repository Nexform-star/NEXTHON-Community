# Contributing to NEXTHON Community

Thank you for your interest in contributing!

We welcome developers of all experience levels.

## Contribution workflow

1. Open an Issue describing your idea.
2. Wait for maintainer feedback.
3. Fork the repository.
4. Create a branch for your contribution.
5. Add your files.
6. Open a Pull Request referencing the Issue.
7. Wait for maintainer review.

Please do not consider an idea approved until a maintainer has reviewed it.

## Code requirements

- Use `.ne` for NEXTHON source files.
- Keep code readable and properly formatted.
- Add comments when they help explain the code.
- Test your programs with the NEXTHON interpreter.
- Avoid unnecessary dependencies.

## Pull Requests

Every Pull Request must:

- Explain the changes.
- Reference an existing Issue.
- Follow the repository structure.
- Pass maintainer review.

Only maintainers can merge contributions into `main`.

Thank you for helping NEXTHON grow!
